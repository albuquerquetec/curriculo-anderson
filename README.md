# Portfólio profissional — Anderson Albuquerque

Site estático com a página inicial e o currículo detalhado. O conteúdo resume a trajetória publicada no LinkedIn.

## Arquivos

- `index.html` — página inicial
- `curriculo.html` — currículo completo, com impressão ou PDF pelo navegador
- `styles.css` — visual das duas páginas
- `favicon.svg` — ícone

## Ver localmente

Abra `index.html` no navegador. Os links entre as páginas usam caminhos relativos.

## Publicar

O site é servido pelo GitHub Pages a partir da branch `main`, pasta raiz.

Endereço esperado: `https://albuquerquetec.github.io/curriculo-anderson/`

Para atualizar, altere os arquivos, faça commit e envie para `main`. A publicação pode levar alguns minutos.
